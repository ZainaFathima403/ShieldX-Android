# ShieldX---Android
ShieldX — Cybersecurity platform for phishing detection, scam prevention, and real-time online threat analysis.

API Configuration
ShieldX uses the following APIs to power its AI assistant and enhance phishing and malware detection.

1. Groq API — AI Assistant
The Groq API powers the AI Assistant chatbot.
Setup instructions:
Visit Groq Console.
Create an account if you don't already have one.
Generate a new API key and copy it securely.
Configure the key using the app's local configuration method.

2. Google Safe Browsing API — Threat Detection
The Google Safe Browsing API checks scanned URLs against Google's threat database to identify known phishing and malware threats.
Setup instructions:
Visit the Google Cloud Console.
Create a Google Cloud project.
Navigate to APIs & Services → Library and enable the Safe Browsing API.
Open APIs & Services → Credentials.
Create an API key and store it securely.
Configure the key using the app's local configuration method.
